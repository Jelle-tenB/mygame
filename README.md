# mygame (WIP)
This is the first real game I made and I don't really plan on publishing it.

It is a "Higher or Lower" gambling game with a deck of cards. You can bet on if the next card is either higher, lower or the same value as the previous card. As you guess the right values you build up a Score Streak which will reward you with more Score Points. You can spend your Score Points at the end of every round in the shop to add or remove cards in you deck.

Possible planned features:
- Power-ups that may or may not change gameplay.
- Custom art by friends.
